# UV Package Manager - Setup Guide

UrbanReflex uses **uv** as the single package manager for Python dependencies, replacing pip and requirements.txt.

## What is UV?

UV is a fast Python package installer and resolver written in Rust. It's significantly faster than pip and provides better dependency resolution.

**Benefits:**

- 10-100x faster than pip
- Reproducible builds with `uv.lock`
- Single dependency management file
- Professional Python project standard

## Installation

UV is already included in the project. Install it globally:

```bash
# macOS/Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (via scoop)
scoop install uv

# Or via pip
pip install uv
```

## Project Setup

All dependencies are defined in `pyproject.toml`:

```toml
[project]
dependencies = [
    "fastapi[standard]>=0.121.2",
    "motor>=3.7.1",
    # ... more production deps
]

[project.optional-dependencies]
dev = [
    "black>=24.1.1",
    "flake8>=7.0.0",
    "isort>=5.13.2",
    "pre-commit>=4.5.0",
    "pytest>=7.4.0",
]
```

## Common Commands

### Install All Dependencies

```bash
# Install all (production + dev)
uv sync --all-extras

# Install only production
uv sync --no-dev

# Install in development mode
uv venv                    # Create virtual environment
source .venv/bin/activate  # On macOS/Linux
# or
.venv\Scripts\activate     # On Windows
```

### Add a Dependency

```bash
# Add to production
uv add fastapi

# Add to dev (--dev flag)
uv add --dev pytest

# Add specific version
uv add 'django>=4.0,<5.0'

# Add with extras
uv add 'fastapi[standard]'
```

### Remove a Dependency

```bash
# Remove from project
uv remove requests

# Remove dev dependency
uv remove --dev black
```

### Update Dependencies

```bash
# Update all packages
uv sync --upgrade

# Update specific package
uv sync --upgrade-package numpy

# Sync lock file only (no install)
uv lock
```

### Run Commands in Virtual Environment

```bash
# Run Python script
uv run python script.py

# Run backend
uv run uvicorn src.backend.app:app --reload

# Run tests
uv run pytest tests/

# Run Black formatter
uv run black src/backend/
```

### Check Dependency Tree

```bash
# Show all dependencies
uv pip list

# Show outdated packages
uv pip list --outdated
```

## Files

### `pyproject.toml`

Contains all project metadata and dependencies.

**Structure:**

```toml
[project]
name = "urban-reflex"
version = "0.1.0"
dependencies = [...]  # Production dependencies

[project.optional-dependencies]
dev = [...]           # Development dependencies
```

**Sections:**

- `dependencies` - Production packages
- `optional-dependencies.dev` - Dev tools (testing, linting)
- `tool.black` - Black formatter config
- `tool.flake8` - Flake8 linter config
- `tool.isort` - isort import organizer config

### `uv.lock`

Locked dependency versions for reproducible builds. **Don't edit manually** - auto-generated by uv.

## Workflow

### Development Setup

```bash
# Clone project
git clone <repo>
cd UrbanReflex

# Install all dependencies (dev + production)
uv sync --all-extras

# Create and activate virtual environment
uv venv
source .venv/bin/activate  # macOS/Linux
# or
.venv\Scripts\activate     # Windows

# Run backend
uv run uvicorn src.backend.app:app --reload

# Or in another terminal - run frontend
cd src/frontend
npm run dev
```

### Adding Dependencies

When you need a new package:

```bash
# 1. Add to project
uv add numpy

# 2. Update lock file automatically (done by add)
# 3. Commit changes
git add pyproject.toml uv.lock
git commit -m "chore: add numpy for data processing"
```

### Updating Dependencies

To update all packages to latest compatible versions:

```bash
# Update all
uv sync --upgrade

# Commit updated lock file
git add uv.lock
git commit -m "chore: update dependencies"
```

## Dependency Management

### Production vs Dev

**Production** (always installed):

- FastAPI, Motor, pydantic, numpy, etc.
- Used in deployed application

**Dev** (only for development):

- Black, Flake8, isort, pytest, pre-commit
- Tools for code quality, testing, formatting
- Not included in deployed application

### Specifying Versions

```toml
# Any version >= 2.0
"package>=2.0"

# Specific range
"package>=2.0,<3.0"

# Compatible release
"package~=2.0"

# Exact version
"package==2.0.1"
```

### Extras

Some packages offer optional dependencies:

```toml
# Use FastAPI with all extras
"fastapi[standard]>=0.121.2"

# Multiple extras
"package[extra1,extra2]>=1.0"
```

## Comparison: Before and After

### Before (pip + requirements.txt)

```bash
# requirements.txt
fastapi==0.121.2
motor==3.7.1
# ... 50+ lines

# Installation
pip install -r requirements.txt
pip install black flake8 isort pytest  # Dev separately
```

### After (uv + pyproject.toml)

```toml
[project]
dependencies = [...]

[project.optional-dependencies]
dev = [...]

# Installation
uv sync --all-extras
```

**Benefits:**

- Single source of truth
- Version constraints are visible
- Better dependency resolution
- Dev vs production separation clear
- Reproducible builds with uv.lock

## Troubleshooting

### "No virtual environment"

```bash
# Create one
uv venv

# Activate
source .venv/bin/activate  # macOS/Linux
.venv\Scripts\activate     # Windows
```

### "Can't find package"

```bash
# Update package index
uv sync --refresh

# Check package name on PyPI
uv search package-name
```

### Lock file conflicts after merge

```bash
# Regenerate lock file
uv lock --refresh

# Then sync
uv sync --all-extras
```

### Performance is slow

```bash
# Use copy mode (faster on some systems)
export UV_LINK_MODE=copy

# Or permanent setting
uv sync --link-mode=copy --all-extras
```

## CI/CD Integration

In GitHub Actions:

```yaml
- name: Install uv
  uses: astral-sh/setup-uv@v2

- name: Install dependencies
  run: uv sync --all-extras

- name: Run tests
  run: uv run pytest

- name: Run linting
  run: |
    uv run black --check src/backend/
    uv run flake8 src/backend/
    uv run isort --check-only src/backend/
```

## Tips & Best Practices

1. **Always commit uv.lock**: Ensures reproducible builds across machines

   ```bash
   git add pyproject.toml uv.lock
   ```

2. **Use uv run** instead of activating venv every time

   ```bash
   uv run python script.py
   uv run pytest tests/
   ```

3. **Keep dev dependencies separate**: Don't mix dev tools with production

   ```toml
   [project]
   dependencies = [...]  # Only production

   [project.optional-dependencies]
   dev = [...]  # Only dev tools
   ```

4. **Pin major versions only in production**:

   ```toml
   "fastapi>=0.100,<1.0"  # Stable range
   "black>=24,<25"        # Auto-update patch
   ```

5. **Use --all-extras during development**:
   ```bash
   uv sync --all-extras  # Get everything
   ```

If you're still using pip:

```bash
# Switch to uv completely
uv sync --all-extras

# Delete old requirements.txt files
rm requirements.txt requirements-dev.txt

# Update workflow in documentation
# Done! All deps now in pyproject.toml
```
